
# Crazy Bot — My First Discord Bot

## About This Project
Crazy Bot is my first Discord bot project. I created it to learn bot development and programming.

## Project Goals
- Learn how Discord bots work.
- Practice programming and debugging.
- Learn to run a bot using Replit.

## Features
- Connects to Discord.
- Responds to basic commands such as !hello and !ping, if working.
- Runs using Replit.

## Tools Used
- Discord Developer Portal

- Python (if used in my bot)
